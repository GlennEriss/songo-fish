# Matrice de provenance

Les revendications A–M sont vérifiées à partir des artefacts disponibles. La recherche bornée P4 a retrouvé `data/real_matches/match_moves_v1.jsonl` dans Git : 586283 octets et SHA-256 frais `17d9ad…ed18`, identique au manifeste historique. L’identité des octets est donc vérifiée; l’affirmation externe que toutes les parties proviennent effectivement d’humains n’est pas prouvée par le hash seul.

La matrice JSON donne pour chaque revendication le chemin, le type de preuve, la méthode, le résultat et la limitation. Aucun `VERIFIED` n’est utilisé pour assimiler intégrité du dérivé, authenticité des parties humaines et indépendance scientifique.
